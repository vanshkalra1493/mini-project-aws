# Weather Website

A simple weather website built with HTML, CSS and JavaScript. It lets you check the weather for a city in a clean, easy-to-read layout.

## Features

- Search the weather for a city
- Shows current weather conditions
- Responsive layout for phones and desktops
- Built with plain HTML, CSS and JavaScript, so there is nothing to install

## Tech stack

- HTML5
- CSS3
- JavaScript (vanilla)

## Project structure

```
.
├── index.html   # Page structure
├── style.css    # Styling and layout
└── script.js    # Weather logic and page behavior
```
